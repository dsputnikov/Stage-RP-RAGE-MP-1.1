# stagerp

Старый архив RP-проекта.

Репозиторий содержит исходники, клиентские пакеты, языковые файлы, конфиги и legacy-бинарники старого roleplay-проекта.

Проект не обновлялся несколько лет, поэтому может не работать на современных версиях окружения, зависимостей или игрового клиента. Репозиторий сохранён в основном как архив и пример старой реализации.

## О проекте

`stagerp` — это старый проект, связанный с разработкой RP-сервера/клиента.  
В репозитории находятся файлы, которые использовались для работы проекта на момент его актуальности.

Сейчас проект не поддерживается и может требовать доработок для запуска.

## Что есть в репозитории

- исходные файлы проекта;
- клиентские пакеты;
- языковые файлы;
- конфигурационные файлы;
- старые бинарные файлы;
- вспомогательные директории и зависимости.

## Важно

Проект был создан несколько лет назад и давно не обновлялся.

Из-за этого возможны проблемы:

- устаревшие зависимости;
- несовместимость с современными версиями Node.js или других инструментов;
- нерабочие бинарные файлы;
- отсутствие части нужного окружения;
- ошибки при запуске или сборке.

Репозиторий опубликован в архивных целях.  
Используйте его как основу, референс или пример старой реализации.
